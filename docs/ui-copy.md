# 카토피아 문구 기준

## 참고 자료

- [한국닌텐도: 처음부터 시작하는 모여봐요 동물의 숲](https://www.nintendo.com/kr/news/article/77otbivgUusCmTTfAjcXwO)
- [Pikmin Bloom 한국어 공식 소개](https://pikminbloom.com/ko)

두 게임의 한국어 안내를 참고해, 대상과 행동이 바로 드러나는 표현을 사용한다.

## 용어와 말투

- 앱 이름: 카토피아. 화폐: 코인. 지도 단위: 구역.
- 편집 대상: 아이템. 보유 아이템 목록: 보관함.
- 공통 동작: 배치하기, 옮기기, 배치 섞기, 보관하기, 업그레이드.
- 집·카페 등 개별 건물을 설명할 때는 ‘짓기’를 쓴다.
- 생산물을 코인로 바꾸는 동작은 ‘판매’로 부른다.
- 제목과 상태는 짧게 쓴다. 도움이 필요한 상황에서만 해요체로 설명한다.
- 아이템 이름은 자동으로 붙는다(예: ‘숲 1’). 사용자가 이름을 짓거나 바꾸는 기능은 없다.
- 저장 데이터의 식별자는 바꾸지 않는다.

## 설명을 남기는 기준

- 제목·버튼·입력칸을 그대로 풀어 쓴 설명은 삭제한다. 목록 위의 ‘마을 관리’ 같은 별도 제목은 생략한다.
- 감점이 없으면 감점 영역을 숨긴다. 배치 가능한 아이템에 ‘배치 가능’을 반복하지 않고, 제한 조건과 녹지 추천만 표시한다.
- 판매 버튼은 ‘모두 판매 · +코인’로 표시한다. 생산물 종류와 수량은 버튼 위에서 확인할 수 있다.
- 무료 여부, 필요한 재화, 생산 조건, 실패 이유는 남긴다.
- 전체 아이템에 관계없는 효과는 해당 아이템을 선택했을 때만 보여 준다. 예: 양 목장의 녹지 생산 보너스.
- 레벨 진행은 ‘3곳 더 꾸미면 Lv.2’, 업그레이드 효과는 ‘10 km당 1.5개 생산’처럼 조건과 결과를 표시한다.
- 생산물이 없으면 수량 0과 비활성 판매 버튼으로 표시한다. 목적지가 없으면 ‘빈 구역이 없어요’로 알린다.
- 저장 화면에서는 ‘주행 기록 저장 중…’만 표시한다. 실제 처리 상태와 연동하지 않는 단계 안내는 사용하지 않는다.
- 업그레이드 효과는 코드로 확인되는 내용만 안내한다. 모든 아이템에서 나무와 장식이 늘어난다고 설명하지 않는다.
- 거리 검증 실패는 기록의 작은 차이도 실패하는 것으로 오해하지 않도록 ‘주행거리 차이가 커서’로 안내한다.
- 음성은 화면보다 짧게 쓴다. 예: ‘새 구역을 발견했어요’.

## 확인 범위

지도·주행·저장·결과·구역 선택·이동·미리보기·아이템 관리·보관함·로딩·오류 안내와 음성 문구를 검토했다. 가격과 주행 보상, 생산 계산은 유지한다.
