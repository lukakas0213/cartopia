# 카토피아 문구 기준

## 참고 자료

- [한국닌텐도: 처음부터 시작하는 모여봐요 동물의 숲](https://www.nintendo.com/kr/news/article/77otbivgUusCmTTfAjcXwO)
- [Pikmin Bloom 한국어 공식 소개](https://pikminbloom.com/ko)

두 게임의 한국어 안내를 참고해, 대상과 행동이 바로 드러나는 표현을 사용한다.

## 용어

| 개념 | 표기 |
|---|---|
| 앱 이름 | 카토피아 |
| 화폐 | 코인 |
| 지도 단위 | 구역 |
| 이번 주행으로 열린 땅의 넓이 | 탐험 면적 |
| 꾸미는 대상 | 아이템 (종류 이름만 쓰고 개별 이름은 붙이지 않는다) |
| 보관한 아이템 목록 | 보관함 |
| 동작 | 배치하기, 옮기기, 배치 섞기, 보관하기 |
| 아직 열리지 않은 아이템 | ‘공원 발견’처럼 여는 조건만 적는다 |

- 상단 알약에는 지명만 쓴다(‘삼성동’). ‘마을’ 같은 접미사를 붙이지 않는다.
- 구역 크기는 ‘소형/중형’이 아니라 넓이(㎡)로 보여 준다.
- 제목과 상태는 짧게 쓰고, 도움이 필요한 상황에서만 해요체로 설명한다.

## 설명을 남기는 기준

- 제목, 버튼, 입력칸을 풀어 쓴 설명은 넣지 않는다.
- 감점이 없으면 감점 영역을 숨긴다. 탐험 면적이 0이면 요약에서 숨긴다.
- 실패 이유(옮길 수 없는 구역, 코인 부족)는 말풍선이나 버튼 상태로 남긴다.
- 저장 화면에서는 ‘주행 기록 저장 중…’만 표시한다.
- 주행 중 음성 안내는 내비게이션 안내와 겹치지 않게, 탐험 면적이 0.1 km²가 될 때와 그 뒤 1 km²마다 한 번씩만 한다.
