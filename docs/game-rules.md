# 카토피아 게임 규칙 v2 (2026-11-14)

## 1. v1 규칙을 바꾼 이유

| 시스템 | 문제 |
|---|---|
| 생산 · 판매 | 목장과 낚시터가 만든 양털·물고기를 다시 코인으로 바꾸는 순환이라, 주행으로 코인을 받는 것과 결과가 같았다. 주차 후 할 일(판매 버튼)만 늘었다. |
| 아이템 업그레이드 | 코인과 생산물을 내면 생산량이 오르는 구조라, 생산 · 판매가 없으면 의미가 없다. 버튼이 꺼져 있어도 이유가 보이지 않았다. |
| 마을 레벨 | 꾸민 구역 수(3/6/12/20곳)로 카페와 빵집만 열렸다. 숫자의 근거가 없고, 실제 장소와 관계가 없었다. |
| 지형 보너스 | 생산량 +20%라는 보이지 않는 수치였다. |

코인을 버는 경로, 성장 경로, 해금 경로가 각자 다른 숫자로 움직였기 때문에 설명 문구가 많이 필요했다. 화면에서 설명 문구를 덜어 내자 규칙이 보이지 않게 되었다.

## 2. 참고한 게임

| 게임 | 가져온 점 |
|---|---|
| Pikmin Bloom | 걸은 곳 주변 장소의 종류(카페, 공원, 물가 등)에 따라 다른 데코 피크민을 얻는다. → **새 지형을 발견하면 그 지형의 아이템이 열린다.** |
| Pokémon GO (알 부화, 버디) | 정해진 거리를 이동하면 결과가 자동으로 나온다. 화면을 보지 않아도 진행된다. → **주행거리가 쌓이면 아이템이 자란다.** |
| 모여봐요 동물의 숲, Townscaper | 진행을 숫자가 아니라 섬과 마을의 모습으로 보여 준다. → **성장은 나무 · 꽃 · 동물 수로 보인다.** |
| Hay Day, Stardew Valley | 생산 · 판매 순환. 매일 들어와 수확하게 만드는 장치라 차량에서는 맞지 않는다고 판단해 **제외했다.** |

## 3. 원칙

1. 화폐는 코인 하나이고, 버는 방법은 주행 하나다. 안전하게 오래 달릴수록 많이 받는다.
2. 진행 상태는 지도와 마을의 모습으로 보인다. 숫자와 설명 문구는 최소화한다.
3. 주차 후 조작은 배치, 옮기기, 보관, 배치 섞기뿐이다. 수확이나 업그레이드처럼 매번 눌러야 하는 버튼은 두지 않는다.

## 4. 규칙

### 4.1 코인 (변경 없음, Miles.kt)
- 1 km당 10코인 × 안전 배율(0.5~1.5배) + 직접 지나간 새 면적 4,000㎡당 1코인.
- 차량과 GPS의 주행거리 차이가 30%를 넘으면 지급하지 않는다.

### 4.2 배치
- 아이템 9종. 가격 = 기본 가격 × 구역 크기 배수(소형 1, 중형 1.5, 대형 2를 고른 구역마다 더함).
- 아이템마다 놓을 수 있는 지형이 정해져 있다(기존 표 유지). 가장 잘 맞는 지형에서는 카드에 ‘추천’ 배지가 붙고 추천 탭 앞쪽에 나온다. 수치 보너스는 없다.
- 옮기기, 보관, 보관함에서 다시 꺼내기, 배치 섞기는 무료다.

### 4.3 해금: 지형을 발견하면 열린다

| 처음부터 | 공원 발견 | 산림 발견 | 상업지 발견 | 강가 발견 |
|---|---|---|---|---|
| 내 집, 숲, 꽃밭 | 연못, 양 목장 | 사슴 쉼터 | 카페, 빵집 | 낚시터 |

- 발견은 그 지형의 구역이 지도에 한 곳이라도 열리는 것을 말한다(꾸밀 수 없는 큰 산 구역도 포함).
- 아직 열리지 않은 카드는 흐리게 보이고 배지에 ‘공원 발견’처럼 조건만 적는다.
- 주행으로 새 아이템이 열리면 주행 요약에 그 아이템의 그림이 나온다.
- 서울 블록 기준 분포: 주거지 84%, 상업지 7%, 공원 2.5%, 강가 0.9%, 산림 0.6%. 출퇴근만 해도 상업지 · 공원은 금방 열리고, 강가와 산림은 일부러 찾아가야 열린다.

### 4.4 성장: 달린 만큼 자란다
- 배치한 뒤 주행한 거리가 쌓이면 3단계로 자란다. 1단계(배치) → 30 km → 2단계 → 100 km → 3단계.
- 단계마다 나무, 꽃, 동물 수가 늘어난다(1단계 0.7배, 2단계 1배, 3단계 1.3배).
- 보관하거나 옮겨도 쌓인 거리는 유지된다.
- 하루 출퇴근 20 km 기준으로 2단계까지 이틀, 3단계까지 닷새쯤 걸린다.
- 주행으로 단계가 오른 아이템은 주행 요약에 나온다. 아이템 카드에는 단계 점 3개와 다음 단계까지의 막대만 보인다.

### 4.5 삭제한 규칙
생산물(양털, 물고기), 판매, 보관 한도, 아이템 업그레이드(Lv.1~5), 마을 레벨, 지형 보너스 +20%.

### 4.6 기존 저장 데이터
- 아이템 Lv.1 → 0 km, Lv.2~3 → 30 km(2단계), Lv.4~5 → 100 km(3단계)로 바꾼다. 남은 생산물은 버린다.
- 이미 배치한 아이템은 해금 여부와 관계없이 그대로 둔다.

## 5. 화면 (패널 가안 A, 2026-11-14 확정)

고정된 옆 패널 없이 지도를 넓게 쓴다. 위 양쪽에 지명과 코인 알약 두 개만 둔다.

| 화면 | 보이는 것 |
|---|---|
| 홈 | 오른쪽 아래 '아이템 n/9' 버튼(누르면 9종 목록, 잠긴 것은 흐리게 '○○ 발견'), 보관함 버튼(보관한 아이템이 있을 때만) |
| 구역 선택 | 고른 구역 위 말풍선(지형 · 넓이), 화면 아래 폭 전체의 서랍. 고른 카드가 넓어지며 '가격 배치' 버튼이 들어간다 |
| 미리보기 · 옮기기 | 아래 가운데 한 줄 바(그림, 종류, 가격 / 배치하기 · 배치 섞기 · 취소, 또는 여기로 옮기기 · 취소). 옮길 수 없는 구역이면 말풍선에 이유 |
| 배치한 아이템 | 지도 위 아이템 옆에 붙어 다니는 카드: 그림, 종류, 성장 점과 막대, 옮기기 · 배치 섞기 · 보관하기 |
| 주행 요약 | 왼쪽 큰 카드: +코인, 주행 시간 · 주행 거리 · 탐험 면적(0이면 숨김) · 안전 점수 한 줄, 새 아이템, 자랐어요. 지도는 오늘 지나간 곳 전체를 보여 주고, 오늘 연 구역은 노란빛으로 표시 |

아이템에는 이름을 붙이지 않는다(종류 이름만). 구역 크기는 '소형/중형' 대신 넓이(㎡)로 보여 준다. 반쪽 창(폭 900 이하)에서는 아이템 카드, 바, 요약 카드가 화면 아래 폭 전체로 붙고, 요약의 숫자 네 개는 2×2로 놓인다.
