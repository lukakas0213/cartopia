# 지도 데이터 만들기

앱에 들어 있는 서울 지도(`app/src/main/assets/map/seoul`)는 OpenStreetMap 데이터로 만들었습니다. 지도를 다시 만들 때만 필요하고, 앱 빌드에는 필요하지 않습니다.

필요한 패키지: Python 3.10 이상, `shapely` 2.x

| 순서 | 스크립트 | 하는 일 |
|---|---|---|
| 1 | `build_seoul.py <osm 폴더> <출력 폴더>` | 도로망으로 구역을 나누고, 바닥 벡터(도로, 공원, 물, 동 이름)와 함께 1024 px 타일로 자릅니다. |
| 2 | `classify_land.py <기본 osm> <토지이용 osm> <POI osm> <지도 폴더>` | 구역마다 지형(주거지, 상업지, 공원, 산림, 수역 등)을 붙입니다. 환경부 토지피복지도 대분류를 따릅니다. |
| 3 | `add_towers.py <towers.json> <지도 폴더>` | 20층 또는 66 m 이상 건물을 넣습니다. 현대자동차 강남대로 사옥처럼 직접 모양을 만든 랜드마크는 이름으로 표시합니다. |

입력 OSM 데이터는 Overpass API로 받은 JSON입니다. 각 스크립트 맨 위의 설명에 필요한 태그와 쿼리 조건이 적혀 있습니다.

지도를 다시 만들어 구역 번호가 바뀌면 `index.json`의 `version`을 올려야 합니다. 앱은 버전이 다르면 저장된 마을을 처음부터 다시 시작합니다.
